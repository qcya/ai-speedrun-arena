# 第 113 周实机练习记录

[Astra 开局练习回放压缩包](Astra-opening-practice.zip) 保存的是独立单人存档里 Astra 自己的动作。这一局按第 113 周参数运行，实际取得钻石、铁、TNT、橡木和工作台。它在开局练习阶段结束。游戏内存储的完成状态为 false。

解压后，`Astra.mcpr` 可直接放进 Minecraft Java 1.16.1 的 `replay_recordings` 文件夹，在 Replay Mod 的回放查看器中打开。随包的 `observer.jsonl.gz` 记录真实客户端观测，`native-timer.json` 来自游戏计时模组，`take.json` 含本段时长与校验值。这一局使用用户授权的本地窄臂皮肤和简体中文显示。随包的观察数据有出生时钟、背包栏位、原生视角和真实开箱画面状态。回放查看器能显示的界面取决于所安装的回放工具。世界、方块与实体轨迹由回放包保存，重新开同一种子的存档会引入新的随机性。

夏末的冠军回放单独列在 [赛道资料](../course.json)，本目录只提供 Astra 的实机采样。
