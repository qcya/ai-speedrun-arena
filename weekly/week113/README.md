### 搁置回程珍珠

第三颗珍珠用来从烈焰人刷怪笼返回建门的高台。Astra 走到堡垒桥面上的固定位置，等自己的朝向在游戏服务器上也已对准，再跳投。出手后使用 1.16.1 的 **F3 + Shift + F** 逐格缩短视距，最低到 2 个区块。落点区块停止处理实体时，飞行中的珍珠会留在那里。拿齐六根烈焰棒后，Astra 使用 **F3 + F** 逐格调远，珍珠所在区块恢复处理并发生碰撞，触发原版传送。能否搁置取决于实际路径和区块加载范围，仅调低数字无法保证成功。

同张地图有三次独立的实机验证。一局在下界分段从零根打到六根，回程时一刻跨过 77.57 格。另外两局把起始视距设为 16，预置五根烈焰棒来单测回程。两次都用快捷键逐格降至 2，实战捡到第六根，再逐格恢复到 16，最终分别一刻跨过 84.64 和 85.57 格。两次从开始拉远视距到实际传送分别等了 59.843 和 49.643 秒，因此本机的净节时要靠整局分段计时验证。[三局的原生回放哈希、按键、游戏刻与落点](evidence/pearl-stasis.json)

录像观察器给原版键盘处理器确认执行的每次增减记下按键、前后视距与时间。成片里的调节反馈沿用 Minecraft 自己的中文聊天提示；游戏过程和总计时照常继续。

### Windows 或 Linux 复跑

使用自己已有的 Minecraft Java 账号和 Fabric 1.16.1 实例，Loader 0.16.14。文件夹应为该独立客户端中实际放 `mods` 与 `saves` 的一层。安装 Python 3 和 Pillow 后，从仓库根目录执行下列命令。准备程序下载并校验对应版本的 Ranked 与 Replay Mod，再建立一个全新单人存档。也可用 `--ranked-jar`、`--replay-jar` 传入自己的原版模组文件。

```sh
python -m pip install Pillow
python weekly/week113/prepare.py --game-dir "D:/Minecraft/AstraPractice/.minecraft" --world-name W113-01 --skin "D:/Skins/qcya_ovo.png" --autostart
```

默认开局用铁质测重压力板点燃 TNT。命令末尾加 `--shield` 会改用木质压力板，把省下的铁做成盾并装在副手。命令末尾加 `--wait-for-piglins` 可走较稳的下层通道。首箱附近出现成群持剑猪灵时，角色会待在取箱的平台上，等待本次开箱引起的仇恨消退。默认使用原路线的下层通道。`--upper-corridor` 启用实验性高台绕行，角色会在下层出现多只持剑猪灵时走上方搭桥路线。

进入这个实例时，使用本地练习角色名 Astra。通过启动器正常启动。再次开局请更换 `--world-name`，已有存档受到保护。中文语言、瘦臂皮肤和右上透明像素计时设置随实例生成。皮肤图片只需保存在使用者电脑。

### 固定同一局
