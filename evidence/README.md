# v0.1.0 实机验收

环境为 Linux 虚拟桌面、Minecraft Java 1.16.1、Fabric Loader 0.16.14、独立单人生存世界 AI Speedrun Arena | Practice Lab（种子 16101）。运行时为标准游戏速度。模组 SHA-256 为 `0ec7a4f98330b7672fbad6ef578cfb379f49e9684b186027569c2126fd41fb63`。下方是发布版训练场复测，原始数据库包含这一轮全部 22 次提交（含对照、录像、失败与探索）。主机同时运行游戏、执行器与观赛台。参赛脚本为本项目基线和 ASTRA 编写的候选路线。

| 条件 | 方案 | 测量 |
| --- | --- | --- |
| 净场，拾取 1 张红床 | 直取床 | 录像 31 tick；随后比赛两次 30、30 tick |
| 净场，相同取床目标 | 等待再取床 | 32、37 tick |
| 净场，相同取床目标 | ASTRA 边走边挖 | 3 种角度，每种两次；4 次拿到床，2 次用完动作未达标；最快 16 tick |
| 净场，平移 8 格 | 步行 / 疾跑 | 步行 41、41 tick；疾跑 28、28 tick |
| 净场，原木合成 4 块木板 | Oak-to-Planks | 123 tick；物品裁判通过，作为独立训练记录保存 |
| 净场，取床但只走不挖 | 无挖掘对照 | 60 tick 后结束，未达标 |
| 固定村民，取床 | 直取床 | 第 2 tick 后准星检查终止；未对村民发出攻击 |
| 自由活动村民，取床 | 直取床 / 等待再取床 | 直取床 28、24 tick；等待再取床 33、35 tick；这 4 次均成功 |

`minecraft-smoke.mp4` 是 8 秒无声第一人称实机录屏。先显示诊断村民位于准星与床之间（场次 `f5ee92f7249b4da6a4c660c7fbb839a2`），再显示场地重置及成功挖取红床（场次 `c8259de2e4d34908b55032cb39405179`）。

`search.json` 保存参数搜索的六次原始场次 ID 和顺序，`best-bed.json` 是自动导出的最快成功方案。相同角度出现不同结果，由正常运行产生。该小样本只证明存在最快一次，不足以确定不同角度的长期优劣。净场与自由活动村民组分别计时。

在项目根目录运行 `python3 -m arena --data-dir evidence serve`，可在本地查看和回放这些场次。也可用 `python3 -m arena --data-dir evidence show 场次ID` 导出逐次采样。截图为正式测试进行中的实机数据库快照。公开周榜未收到任何提交，完整周赛和末地通关尚未实测。
